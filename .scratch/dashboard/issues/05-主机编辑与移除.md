# 05: 主机编辑与移除

**What to build:** 在设置抽屉里能改一台主机的备注、地址、账号，也能换密码 —— 密码框留空表示不改。能移除一台主机，移除要输入地址确认。某台主机连不上时，它的卡片显示离线与原因，其他主机和整张表照常可用；证书指纹变了要在卡片上提示。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 编辑主机时密码留空即保持原密码，不发生覆盖
- [ ] 移除主机需输入该主机地址确认，取消后什么都不变
- [ ] 移除一台后，其余主机的采集与展示不受影响
- [ ] 主机离线时卡片显示离线与可读原因，不阻塞整页渲染
- [ ] 证书 SHA256 指纹与原记录不一致时卡片给出提示
