# 02: 虚拟机聚合表

**What to build:** 主机卡下面出现一张表，装下所有已接入主机的虚拟机：名称、主机、IP、操作系统、电源状态、内存、磁盘、Tools 状态。能按名称或 IP 搜索，点表头按名称/电源状态/内存/磁盘排序，能按主机筛选，能点刷新并看到"最后更新于"。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 关机虚拟机也有操作系统名（回退到配置里的客户机类型），不出现空白
- [ ] 内存列显示配置内存，运行中且 Tools 正常时括号附实时占用
- [ ] 磁盘列为该虚拟机各虚拟磁盘容量之和
- [ ] 搜索按名称和 IP 即时过滤
- [ ] 排序支持 名称/电源状态/内存/磁盘，可切升降序，默认名称升序
- [ ] 刷新为手动触发，显示"最后更新于 HH:mm:ss"，10 秒内重复点击走缓存
- [ ] 三台并发采集、各自超时 10 秒，单台失败不拖垮整页
- [ ] 点一行展开只读详情：CPU 核数、内存、磁盘、VMX 路径、UUID、开机时间、IP
