# vm_bord

ESXi 虚拟机巡检看板 —— 一个只监听本机的小服务，把三台 ESXi 单机上的 79 台虚拟机收进一页表格，支持手动刷新、搜索、排序和开关机。

## 为什么有这个东西

三台 ESXi（`192.168.2.152` / `.153` / `.154`）平时要分别登录三个 Host Client 页面来回切。这个看板把三台合成一页：顶部是主机资源卡，中间是全部虚拟机的聚合表格，能就地开机、优雅关机、优雅重启。

三台的 22 端口（SSH）都是关闭的，只有 443 上的 vSphere Web Services API 可用，所以全程走 SOAP API，不登机器跑命令。

## 形态

- **主体**：本地 Python 服务 + 零构建的静态页面，浏览器访问 `http://127.0.0.1:8787`。
- **入口**：`start.bat` / 桌面快捷方式；另有一个 DSH Desktop 侧栏启动器面板负责一键拉起。
- **不做**：不做 DSH 内嵌面板 —— 官方规范禁止 iframe 嵌入 Host 托管的页面，且第三方插件每次改动都要手动重启 Desktop，不适合一个还在反复调的看板。详见 [ADR 0001](docs/adr/0001-独立本地页面与DSH启动器壳.md)。

## 环境

- Windows
- Python 3.12
- `pyvmomi`（唯一非标准库依赖）

## 安全

只监听 `127.0.0.1`；主机密码用 Windows DPAPI 加密后就地存放，机器与用户绑定，页面永不回显密码。`data/` 不进版本库。
